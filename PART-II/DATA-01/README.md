# DATA-01

브랜드 점포와 서울 상권을 연결한다.

## 입력

- 행정안전부 식품·휴게음식점
- 소상공인시장진흥공단 상가정보
- 공정거래위원회 가맹 브랜드 목록
- 서울시 상권 경계

원본은 레포 최상단 `Datasets`에서 읽는다.

## 작업

1. 공정위 브랜드명을 표준화한다.
2. 상가정보와 행정안전부 자료에서 점포 후보를 생성한다.
3. 완전일치와 후보일치를 분리한다.
4. 주소·좌표·영업상태를 검증한다.
5. 서울 점포 좌표를 상권 경계에 공간 조인한다.
6. 연결 실패와 제외 사유를 기록한다.

## 필수 출력

- `brand_store_area_map.parquet`
- `data01_quality_report.csv`
- `brand_name_mapping.csv`

결과는 `PART-II/DATA-01`에 저장한다.

## 주의

- 접두어 일치만으로 브랜드 점포를 확정하지 않는다.
- 공간 연결 성공률과 제외 사유를 보고한다.
- 원본 주소·원본 데이터는 Git에 올리지 않는다.
