# DATA-01 | 브랜드 점포와 서울 상권 연결

## 1. 역할

DATA-01은 각 프랜차이즈 브랜드가 실제로 어느 지역과 서울 상권에 입점해 있는지 확인하고,
이를 MODEL-01이 사용할 수 있는 기준 데이터로 구축한다. 공정거래위원회의 브랜드 목록을
기준으로 브랜드명을 표준화하고, 소상공인시장진흥공단의 점포 정보에서 해당 브랜드의 실제
점포를 찾는다. 행정안전부 데이터는 주소와 영업 상태를 교차 확인하는 데 활용한다.
서울 점포는 좌표를 서울시 상권영역 경계와 결합하여 소속 상권 코드를 부여한다.

## 2. 입력

- 행정안전부 식품·휴게음식점 (서울만 포함된 파일)
- 소상공인시장진흥공단 상가정보 (전국 17개 시도, `상권업종소분류명 == "빵/도넛"` 필터)
- 공정거래위원회 가맹 브랜드 목록 (`indutyMlsfcNm == "제과제빵"` 필터, 178개 브랜드)
- 서울시 상권 경계 (shapefile, https://data.seoul.go.kr/dataList/OA-15560 , 1,650개 상권 폴리곤, EPSG:5181)

원본은 레포 최상단 `Datasets`에서 읽는다.

## 3. 방법론과 선정 이유

### 3.1 브랜드명 표준화

공정위 브랜드명을 괄호 제거/특수문자 제거 방식으로 정규화하되, 두 가지 특수 케이스를 처리한다.

- **괄호 별칭**: "티엠티피자(TMT피자)"처럼 괄호 안에 영문/축약 별칭이 있는 경우, 괄호 제거
  버전과 괄호 안 내용 버전을 모두 매칭 후보로 등록한다.
- **슬래시 병기**: "던킨/던킨도너츠"처럼 "/"로 여러 이름이 나열된 경우, 단순히 "/"만 제거하면
  "던킨던킨도너츠"라는 실존하지 않는 문자열이 되어 실제 매장과 전혀 매칭되지 않는 문제가
  있었다. "/"를 기준으로 분리해 각각을 독립된 검색어로 등록해 해결했다 (이 수정으로 던킨
  매칭 건수가 1건에서 502건으로 증가).

### 3.2 점포 매칭 — 신뢰도 4단계

문서 지침("접두어 일치만으로 브랜드 점포를 확정하지 않는다")에 따라 단일 규칙이 아닌
4단계 신뢰도 체계를 사용한다.

| 신뢰도 | 조건 | 비고 |
|---|---|---|
| high | 정규화한 상호명과 브랜드명이 완전일치 | |
| medium | 상호명이 브랜드명으로 시작(접두어), 브랜드명 4자 이상 | |
| medium_short_brand | 접두어 일치하나 브랜드명 4자 미만 | 검토 대상 |
| low | 브랜드명이 상호명 중간/뒤에 위치(비접두어) | 검토 대상 |

**왜 접두어 기준으로 나눴는가**: 초기에는 단순 포함관계(`contains`)로 매칭했으나, 검토
과정에서 "오복호두"(브랜드 아님, "오"+"복호두"가 우연히 겹침), "동그라미"/"쉐라미"
(브랜드 "라미"가 무관한 단어 중간에 우연히 포함됨) 같은 오탐이 다수 발견되었다. 접두어
기준으로 좁히자 이런 오탐 대부분이 자동으로 사라졌다.

**왜 브랜드명 길이를 별도로 취급하는가**: 접두어 일치여도 브랜드명이 짧으면("라미" 2자)
완전 무관한 개인 상호("라미제과")와 우연히 같은 글자로 시작할 뿐인지 구분할 수 없다.
표본 검토 결과 "라미"(8건 전수 확인)는 모두 정상 매칭이었고, "던킨"(약 400건),
"복호두"(약 90건)도 대표 표본 검토 결과 정상으로 확인되어 `medium`으로 승격했다.
나머지 짧은 브랜드명은 미검토 상태로 `medium_short_brand`에 남아 있다.

**재현성**: 브랜드명 변형(variant)을 `set()`으로 관리하면 파이썬 문자열 해시 랜덤화로
인해 실행할 때마다 중복 제거 결과가 달라지는 문제가 있어, `sorted()`로 순서를 고정하고
중복 제거 시 신뢰도 우선순위(high > medium > medium_short_brand > low)를 명시적으로
지정했다.

### 3.3 제외 처리

- **자동 제외(8건)**: 상호명에 "배송비"가 포함된 경우(온라인 주문 항목이 상가업소 데이터에
  잘못 섞여 들어간 것으로 추정) 및 수동 검증으로 실존하지 않음이 확인된 상호("심봉사도로케통닭").
- **행안부 교차검증 제외(37건)**: 영업상태가 "폐업"으로 확인된 경우.
- **삭제하지 않고 표시만 하는 경우**: 슬로건/문구로 의심되나 존재 여부가 확정되지 않은
  4건(예: "흥부가기가막혀")은 `review_needed`로 표시만 하고 삭제하지 않았다.

### 3.4 행정안전부 교차검증

주소를 정규화(공백/특수문자 제거)해 소상공인 주소가 행안부 주소에 포함되는지 확인하고,
후보가 여러 개면 상호명까지 대조해 확정한다. 상호명 대조는 "상호명+지점명 결합형"으로
먼저 시도하고, 실패하면 "상호명만(지점명 제외)"으로 한 번 더 시도한다(지점명 표기가
데이터셋 간에 다를 수 있기 때문). 이 fallback으로 늘어난 건수는 1건에 그쳐, 대부분의
미검증 건은 표기 차이가 아니라 행안부 데이터 자체에 해당 매장이 없는 경우로 판단했다
(실제로 "파리바게뜨장위레디언트점" 사례를 주소로 직접 조회해 같은 건물의 다른 업체
3곳만 확인되고 해당 매장은 없음을 확인).

### 3.5 서울 상권 공간조인

매장 좌표(WGS84)를 상권 경계 shapefile과 동일한 좌표계(EPSG:5181)로 변환한 뒤
`geopandas.sjoin`으로 폴리곤 내부 포함 여부(`within`)를 확인한다. 폴리곤 밖으로 판정된
점 중 상권 경계에서 300m 이내인 경우 가장 가까운 상권으로 근접 매칭한다.

**왜 300m인가**: 초기 100m 기준에서는 실패 건이 344건이었으나, 실패 건의 최근접 상권
거리 분포를 확인하니 중앙값이 202m, 75%가 340m 이내였다. DATA-02가 상권 경쟁 분석에서
500m를 의미 있는 반경 단위로 사용하고 있어, 그보다 보수적인 300m를 절충안으로 채택했다.
300m로 확대한 결과 실패 건은 46건으로 줄었으며, 이 46건은 최근접 상권까지 평균 291m
(최대 1,340m) 떨어져 있어 상권으로 지정되지 않은 구역(주거지 등)에 위치한 것으로 추정한다.

`area_geometry_raw`(DATA-02 산출물의 한 컬럼)는 상권 폴리곤이 아니라 서울시 상권
기준정보의 면적값(RELM_AR)이라는 점을 DATA-02 담당자에게 확인했으며, 실제 폴리곤은
서울 열린데이터광장에서 별도로 내려받아 사용했다(입력 4번 참고).

## 4. 최종 산출물

- `brand_store_master.parquet` — 전국 브랜드 점포 마스터 (한 행 = 중복 제거된 물리적 점포 1개, 6,120행)
- `brand_ccg_presence.parquet` — 브랜드 x 전국 시군구 집계 (2,019행)
- `brand_area_presence.parquet` — 브랜드 x 서울 상권 집계 (950행)
- `brand_name_mapping.csv` — 브랜드 표준화 대응표
- `data01_quality_report.md` — 품질보고서 (연결률, 제외 사유, 알려진 한계 상세 기록)

결과는 `PART-II/DATA-01`에 저장한다.

> 최초 계획했던 `brand_store_area_map.parquet` 단일 파일, `data01_quality_report.csv`
> 대신, DATA-01 상세 스펙(결과물 형태)에 따라 마스터 테이블과 집계 테이블(전국 시군구 /
> 서울 상권)을 분리하고 품질보고서는 `.md`로 최종 확정했다.

## 5. 품질 원칙

- 모든 식별자는 문자열로 저장한다.
- 원문 열과 표준화 열을 구분한다 (`store_name_raw`/`store_name_std`, `address_raw`/`address_std`).
- 매칭 신뢰도(`match_confidence`)와 매칭 방식(`match_method`)을 항상 함께 기록한다.
- 제외된 레코드도 삭제하지 않고 `exclusion_reason`과 함께 보존한다.
- 공간 연결 실패도 `spatial_join_status`로 사유를 구분해 기록한다(비대상/좌표없음/실패/근접매칭 등).
- 원본 주소·원본 데이터는 Git에 올리지 않는다.

## 6. 알려진 한계

1. 브랜드명 중간에 다른 단어가 삽입된 상호명은 매칭되지 않는다
   (예: "베이커리라운지24" ↔ 실제 상호 "베이커리할인매장라운지24").
2. 행안부 교차검증은 데이터 자체의 커버리지 한계로 서울 매장의 17.9%만 가능했다
   (미검증이 매장의 비실존을 의미하지는 않는다).
3. 소상공인 데이터는 건물 단위 주소까지만 제공해 층/호수 정보가 없어, 대형 건물
   (백화점, 복합몰) 내 여러 입점업체를 정밀하게 구분하지 못한다.
4. 공간조인은 상권 경계 300m 이내 근접 매칭까지만 허용했으며, 46건은 상권 미지정
   구역에 위치한 것으로 추정되어 상권코드를 부여하지 못했다.
5. 178개 브랜드 중 54개는 활성 매장 매칭이 0건이다. 대부분 2025~2026년 등록된
   신생/소규모 브랜드로 추정되나, 전수 검색 확인은 시간 제약상 수행하지 못했다.
6. `medium_short_brand` 162건, `low` 216건은 개별 검토가 완료되지 않은 상태로 남아
   있다(`store_match_review_needed.csv` 참고). MODEL-01에서는 이 신뢰도 구간을
   가중치를 낮춰 사용하거나 제외하는 것을 권장한다.
