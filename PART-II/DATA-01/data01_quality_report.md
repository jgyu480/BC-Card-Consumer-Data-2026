# DATA-01 품질보고서

작성일: 2026-09-07
데이터 기준일: 2026-06-30

## 1. 개요

공정거래위원회 브랜드 목록(제과제빵 업종)을 기준으로 소상공인시장진흥공단 상가정보에서
실제 점포를 매칭하고, 행정안전부 데이터로 영업상태를 교차검증한 뒤, 서울 매장에 한해
상권 경계 폴리곤과 공간조인하여 상권코드를 부여했다.

## 2. 브랜드 및 점포 수

- 대상 베이커리 브랜드(공정위, 제과제빵 업종): **178개**
- 전국 "빵/도넛" 업종 전체 점포(소상공인시장진흥공단): 31,168개
- 브랜드 매칭된 점포(자동 제외 전): 6,120건
- 최종 활성 점포(제외 처리 후, `store_status="영업중"` + `"미확인"`): 6,075건
- 자동/교차검증 제외: 45건 (사유는 4절 참고)

### 신뢰도별 분포 (`match_confidence`)

| 신뢰도 | 건수 | 설명 |
|---|---:|---|
| high | 1,601 | 브랜드명과 상호명 완전일치 |
| medium | 4,141 | 브랜드명이 상호명 접두어로 일치, 브랜드명 4자 이상 |
| medium_short_brand | 162 | 접두어 일치하나 브랜드명이 4자 미만(예: "라미", "복호두") — 동명이인 개인 상호와 혼동 가능성이 있어 검토 대상으로 별도 표기. 실제로 "던킨", "복호두"는 검토 결과 흔한 일반 명사가 아니라 오탐 위험이 낮음을 확인하고 medium으로 승격 처리함. 나머지 162건은 미검토 상태로 남아있음 |
| low | 216 | 브랜드명이 상호명 중간/뒤에 위치(비접두어) — 진짜 매장(예: 운영법인명이 앞에 붙는 "비알던킨도너츠~")과 오탐(예: "오복호두")이 섞여 있어 개별 검토 필요 |

- 활성 매장이 없는 브랜드: 178개 중 **54개**. 브랜드명 확인 결과 대부분 2025~2026년 등록된 신생/소규모 브랜드로 추정되며, 일부는 공식 브랜드명과 실제 매장 간판 표기가 달라(예: "베이커리라운지24" ↔ 실제 상호 "베이커리할인매장라운지24") 매칭되지 못한 것으로 확인됨.

## 3. 데이터 연결률

- 좌표(경도/위도) 보유율: 100% (결측 0건)
- 주소(지번 또는 도로명) 보유율: 100% (결측 0건)
- 시군구코드(`ccg_id`) 보유율: 100%
- 서울 상권(`area_id`) 연결률: 서울 소재 매장 1,123건 중 **1,077건(95.9%)** 연결 성공
  - 폴리곤 내부 정확 매칭(`matched`): 779건
  - 근접 매칭, 폴리곤 경계 300m 이내(`matched_nearest_300m`): 298건
  - 연결 실패(`failed_out_of_boundary`): 46건 — 최근접 상권까지 평균 291m, 최대 1,340m 떨어져 있어 상권으로 지정되지 않은 구역(주거지 등)에 위치한 것으로 추정
- 행안부 데이터 기준 영업상태 교차검증률: 서울 소재 매장 1,123건 중 **201건(17.9%)** 만 검증 가능
  - 검증 성공 중 영업중 164건, 폐업 37건
  - 나머지 922건은 "미확인"(존재하지 않는다는 뜻이 아니라, 행안부 데이터 자체의 커버리지 한계 또는 대형 건물 내 여러 업체가 동일 주소를 공유해 특정이 어려운 경우)

## 4. 제외 사유

| 사유 | 건수 |
|---|---:|

| 수동 검증 결과 실제 존재하지 않는 상호로 확인됨 ("심봉사도로케통닭") | 1 |
| (자동 제외 소계) | 8 |
| 행안부 교차검증 결과 폐업 확인 | 37 |
| **총 제외** | **45** |

슬로건/문구로 의심되나 존재 여부가 확정되지 않은 4건("흥부가기가막혀", "카페베트남" 등)은 삭제하지 않고
검토 필요 표시만 남겨두었다.

## 5. 검토 필요 항목 (`store_match_review_needed.csv`)

- medium_short_brand + low 등급 합계: 378건이 `review_needed=True`로 표시됨
- 이 중 던킨(약 400건), 복호두(약 90건)는 표본 검토를 통해 정상 매칭으로 확인되어 medium으로 승격 처리함
- 나머지는 사람이 개별 확인해야 하는 상태로 남아 있으며, 추천 모델 사용 시 신뢰도가 낮은 항목으로 분리 사용을 권장함

## 6. 알려진 한계

1. **브랜드명 중간에 다른 단어가 삽입된 상호명은 매칭되지 않음**
   (예: "베이커리라운지24" → 실제 상호 "베이커리할인매장라운지24")
2. **행안부 교차검증은 데이터 자체의 커버리지 한계로 서울 매장의 17.9%만 가능**
   (미검증 = 존재하지 않는다는 뜻 아님)
3. **소상공인 데이터는 건물 단위 주소까지만 제공** — 층/호수 정보가 없어
   대형 건물(백화점, 복합몰) 내 여러 입점업체를 정밀하게 구분하지 못함
4. **공간조인은 상권 경계 300m 이내 근접 매칭까지만 허용** — 46건은 상권 미지정
   구역(주거지 등)에 위치한 것으로 추정되어 상권코드를 부여하지 못함
5. **54개 브랜드는 활성 매장 매칭 0건** — 대부분 신생/소규모 브랜드로 추정되나
   전수 검색 확인은 시간 제약상 수행하지 못함
