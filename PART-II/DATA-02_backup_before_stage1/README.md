# DATA-02

서울 상권별 소비·시장·경쟁 특성을 구축한다.

## 입력

- BC카드 2026년 1월~6월 소비데이터
- 서울시 점포-상권 2026년 1·2분기
- 서울시 추정매출-상권 2026년 1·2분기

원본은 레포 최상단 `Datasets`에서 읽는다.

## 행 단위

`area_id × period_q`

## 필수 출력

- `area_feature_master.parquet`
- `data02_quality_report.csv`
- `bc_bakery_industry_mapping.csv`

결과는 `PART-II/DATA-02`에 저장한다.

## 핵심 원칙

- BC카드 값은 자치구 수준이다.
- 서울시 값은 상권 수준이다.
- 자치구 BC값을 상권 고유 소비값으로 표현하지 않는다.
- 실제 0과 결측을 구분한다.
- 법인·외국인은 일반 성별·연령 분모에서 제외하고 별도 집계한다.
- BC 제과 업종 코드는 실제 분류표를 보고 확정한다.
