# DATA-04 브랜드 문맥 특징 사용 결정

## 결론

1. `menu_*` 원시 키워드 횟수는 홈페이지 분량·반복 메뉴의 영향을 받으므로 모델 입력으로 사용하지 않는다.
2. 메뉴 특징은 공식 텍스트에서 해당 메뉴군이 관측됐는지를 뜻하는 이진 변수(`*_present`)만 사용한다.
3. 공식 HTML에서 가격 후보를 찾은 브랜드는 3/24개뿐이다. 가격대·저가/고가 변수는 이번 MODEL-01에서 생성하거나 학습하지 않는다.
4. 800자 이상 공식 텍스트가 있는 브랜드만 TF-IDF 문맥 임베딩 실험에 사용한다.
5. 이 문맥 데이터는 기존 입점 이력을 보완하는 보조 실험용이다. 매출, 성공 확률, 인과효과를 뜻하지 않는다.
