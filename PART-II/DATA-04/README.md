# DATA-04 브랜드 컨텍스트

## 원칙

1. 가격과 메뉴는 공식 홈페이지·공식 메뉴판 등 확인 가능한 출처만 사용한다.
2. 저가·고가 등급을 사람이 임의로 입력하지 않는다.
3. 가격대는 동일 메뉴 카테고리의 중앙가격을 기준으로 사후 계산한다.
4. 메뉴 비중은 수집된 메뉴 개수를 카테고리별로 집계해 계산한다.
5. 브랜드 설명 원문과 URL을 함께 보존한다.
6. 자연어 임베딩은 원문 수집·검수 완료 후 생성한다.
7. 배달앱·블로그 가격은 공식 출처가 없을 때 보조자료로만 사용한다.

## 파일

- brand_source_registry.csv: 브랜드별 공식 출처
- brand_menu_items.csv: 메뉴 한 개당 한 행
- brand_context_features.csv: 모델용 브랜드별 집계 특성
