# APP-01

브랜드 중심 대시보드의 화면 골격을 제작한다.

## 바로 사용할 파일

- `result_schema.json`: 모델 결과 계약
- `mock_recommendations.json`: 개발용 가짜 추천 결과

두 파일은 최종 사용 경로에 있으므로 이동하지 않는다.

## 입력

- 브랜드
- 희망 출점 수 1·2·3개

## 화면

- 브랜드 입점 DNA
- 근거 점포 수
- 개별 추천 상권과 적합도
- 긍정 요인과 위험 요인
- 1~3개 출점 포트폴리오
- 조합 추천 이유
- 데이터 기준시점과 모델 한계

## 필수 동작

1. 브랜드 변경 시 DNA와 추천 결과가 달라져야 한다.
2. 출점 수 변경 시 해당 개수의 조합만 표시한다.
3. 구조화된 수치와 설명을 함께 표시한다.
4. mock 결과임을 화면에 표시한다.
5. 원본 BC카드 데이터와 API 키를 앱에 포함하지 않는다.
