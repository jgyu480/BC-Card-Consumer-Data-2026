# 프로젝트 공통 규격

## 1. 목적

기존 베이커리 프랜차이즈 본사 사업개발팀을 위한 브랜드 맞춤형 서울 출점 포트폴리오 추천 서비스를 구축한다.

전국 실제 점포가 입점한 소비환경을 바탕으로 브랜드별 입점 DNA를 구성하고, 서울 후보 상권과의 적합도를 평가한다. 사용자가 브랜드와 희망 출점 수를 선택하면 함께 검토할 1~3개 상권 조합과 추천 근거를 제시한다.

## 2. 분석 범위

- 대상 업종: 베이커리 프랜차이즈
- 사용자: 프랜차이즈 본사 사업개발팀
- 추천 지역: 서울특별시
- 추천 단위: 서울시 상권분석서비스의 상권
- BC카드 기간: 2026년 1월~6월
- 서울시 데이터: 2026년 1분기·2분기
- 입력: 브랜드, 희망 출점 수 1~3개
- 출력: 브랜드 DNA, 개별 상권 적합도, 출점 조합, 긍정·위험 요인

## 3. 공간 단위

- 실제 브랜드 점포: 개별 점포 좌표
- BC카드 소비데이터: 전국 시군구
- 서울시 상권데이터: 서울 상권
- 최종 추천 결과: 서울 상권

BC카드 데이터는 자치구 수준이므로 상권 자체의 고유 소비값으로 표현하지 않는다. 서울 상권에는 해당 상권이 속한 자치구의 BC 소비 특성을 결합한다.

## 4. 후보 상권 규칙

1. 유효한 서울 상권 코드와 공간정보가 있는 상권만 사용한다.
2. 선택 브랜드의 기존 점포가 동일 상권 안에 있으면 후보에서 제외한다.
3. 기존 점포로부터 500m 미만인 후보는 자동 제외하지 않고 근접 위험으로 표시한다.
4. 복수 출점 조합에는 상권 간 거리와 자치구 분산을 반영한다.
5. 임대료·공실 정보가 없으면 0으로 대체하지 않고 한계로 표시한다.

## 5. 점수 구성

개별 상권 적합도:

- 브랜드 DNA 일치도
- 시장 기회
- 경쟁 위험
- 기존 점포 근접 위험

복수 출점 조합:

- 개별 상권 적합도
- 자치구 및 지역 분산
- 상권 간 근접성
- 소비자 구성 중복 위험

## 6. 주장 범위

본 모델은 브랜드의 현재 입점 패턴과 후보 상권 환경의 적합성을 평가한다.

다음은 주장하지 않는다.

- 신규 점포 예상 매출
- 출점 성공 확률
- 출점의 인과효과
- 특정 건물이나 공실에 대한 최종 출점 결정

## 7. 검증

- 실제 입점 상권 일부를 숨긴 뒤 Recall@K와 MRR 측정
- 브랜드 미반영 일반 상권 순위와 비교
- BC카드 특성 포함·제외 모델 비교
- 대표 브랜드 간 추천 상권 중복률 비교
- 기존 점포 동일 상권 제외 여부 검사
- 거리·경쟁 조건 변화에 따른 민감도 분석

## 8. 결측값

- 실제 0은 0으로 유지한다.
- 미제공 또는 조인 실패는 NULL로 유지한다.
- 분모가 0이거나 결측이면 비율도 NULL이다.
- 관측 여부와 결측 사유를 별도 열로 기록한다.

## 9. 보안

- BC카드 원본은 Git에 올리지 않는다.
- 외부 원본 ZIP·JSONL·CSV는 Git에 올리지 않는다.
- `.env`와 API 키는 Git에 올리지 않는다.
- 앱에는 공개 가능한 집계 결과만 사용한다.
- 원본 주소와 점포 좌표를 대시보드에 직접 노출하지 않는다.
