# MODEL-01 공통 검증 규격

- 후보 상권: 서울 상권 1,650개
- 기본 양성 표본: `match_confidence`가 high 또는 medium인 서울 점포
- 영업상태 규칙: 영업중 또는 미확인
- 브랜드-상권 양성쌍: 882개
- 검증 대상 브랜드: 24개 (서로 다른 입점 상권 4개 이상)
- 검증 방식: 브랜드별 기존 입점 상권 1개를 숨기는 5개 난수 시드 반복 검증
- 평가 후보: 해당 브랜드의 학습용 기존 입점 상권을 제외한 모든 서울 상권
- 공통 지표: Macro HitRate@5/@10/@20, Macro NDCG@5/@10/@20, 평균 순위
- 해석 범위: 숨긴 기존 입점 패턴을 복원하는 능력이며, 매출·수익·인과효과를 의미하지 않음
