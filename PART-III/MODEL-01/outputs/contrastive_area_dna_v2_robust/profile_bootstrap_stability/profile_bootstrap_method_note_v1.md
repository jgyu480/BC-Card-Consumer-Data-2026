# 브랜드 DNA 프로필 재표본 안정성

이 검증은 모델의 매출 예측 정확도를 측정하지 않는다.

각 브랜드의 기존 상권들을 복원추출해 브랜드 환경 중심점을 50회 다시 만들고,
원래의 상권 단위 DNA 후보 Top20·Top50과 얼마나 유지되는지를 측정한다.

- high_profile_stability: 브랜드 환경 적합 후보가 표본 변화에도 비교적 유지됨
- moderate_profile_stability: 추천은 가능하나 현장 검토를 함께 권장
- low_profile_stability: 기존 상권 수 또는 환경 일관성이 부족하므로
  기본 추천 대신 보수 시나리오와 근거를 함께 제시

이는 기존 입점을 성공 라벨로 사용하지 않는 안정성 검증이다.
