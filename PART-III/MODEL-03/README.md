# MODEL-03 — Partner-Data Enhanced New-Store Revenue Forecaster

## 목적

MODEL-03은 프랜차이즈 본사가 제공하는 점포별 월매출·개점일·점포 규모 데이터를 결합해,
특정 브랜드의 신규 점포가 특정 상권과 규모에서 향후 12개월 동안 만들 가능성이 있는 매출을 예측하는
파트너 전용 모델이다.

대상 함수는 다음과 같다.

\[
\widehat{R}_{b,r,s}
=
f(
b,
r,
s,
\text{site},
\text{competition},
\text{historical store performance}
)
\]

- `b`: 브랜드
- `r`: 상권
- `s`: 점포 규모
- `site`: 후보 물건의 위치·임대료·계약 조건
- `competition`: 경쟁점 및 동일 브랜드 기존점
- `historical store performance`: 본사가 제공한 과거 점포 성과

## MODEL-02와의 차이

| 구분 | MODEL-02 | MODEL-03 |
|---|---|---|
| 핵심 데이터 | 공개 상권 매출·점포 데이터 | 본사 점포별 월매출 및 개점 이력 |
| 결과 | 실제 상권 매출환경·현장검증 순서 | 브랜드별 신규점 12개월 매출 예측 |
| 브랜드 반영 | 직접 검증 불가 | 브랜드별 실제 성과로 직접 학습 |
| 규모·투자효율 | 비용 데이터 부족 시 보류 | 면적·임대료 입력 시 계산 가능 |
| 배포 대상 | 공개 데이터 기반 분석 | 본사 또는 데이터 제휴 파트너 |

## 현재 단계: 합성 데이터 프로토타입

현재는 실제 본사 데이터가 없으므로, 합성 데이터로 다음만 검증한다.

1. 본사 입력 데이터의 필수 열과 품질 기준
2. 개점 시점 이전 정보만 사용하도록 막는 누수 방지 구조
3. 시간 차단 방식의 학습·검증 파이프라인
4. 브랜드 단독 모델과 다브랜드 공통 모델의 입력·출력 구조
5. 매출 예측·투자효율·불확실성 표시의 인터페이스

합성 데이터에서 나온 성능 수치는 실제 브랜드 성능이나 사업 효과를 증명하지 않는다.

## 본사 입력 최소 계약

| 데이터 | 필수 | 설명 |
|---|---:|---|
| brand_id | 예 | 브랜드 식별자 |
| store_id | 예 | 점포 식별자 |
| opening_date | 예 | 개점일 |
| monthly_sales_won | 예 | 점포별 월매출 |
| sales_month | 예 | 매출 귀속월 |
| address 또는 latitude/longitude | 예 | 상권·경쟁점 연결용 위치 |
| store_area_m2 | 권장 | 규모 효과 학습 |
| monthly_rent_won | 권장 | 투자효율 계산 |
| initial_investment_won | 권장 | 투자효율 계산 |
| closing_date 또는 operating_status | 권장 | 생존·폐점 편향 점검 |

## 검증 원칙

- 과거에 개점한 점포만으로 학습하고 이후에 개점한 점포를 검증한다.
- 각 점포의 예측에는 개점일 이전에 알 수 있었던 상권·경쟁·물건 변수만 사용한다.
- 평가는 WAPE, MASE, 상위 후보 Lift, 순위상관, 예측구간 적중률로 수행한다.
- 브랜드별 표본이 부족하면 브랜드 단독 매출예측을 제공하지 않고 공통 모델 기반의 넓은 구간 시나리오만 제공한다.

## 디렉터리

- `raw/partner_input_template/`: 본사 입력 템플릿
- `raw/synthetic/`: 파이프라인 시험용 합성 데이터
- `intermediate/`: 누수 없는 학습 테이블
- `outputs/`: 예측·검증·입력 QA 결과
- `scripts/`: 재현 가능한 생성·학습 스크립트
